KILN Embed Test

Willkommen auf meiner Website

Dies ist eine Test-Seite um das KILN Chat-Widget zu testen. Klicke auf den orangen Chat-Button unten rechts um den Agent zu starten.

Das Widget wird per <script>-Tag eingebunden und erstellt automatisch einen Floating-Button mit iframe-Chat.

So funktioniert es:

Ersetze yoga-munich-assistent im Script unten mit dem Slug deines Agents.

<script src="http://localhost:3000/api/embed/yoga-munich-assistent.js" async></script>
